# WORK STEP（ワークステップ）デモ

SBI-U ベンチャーチャレンジ 2026 ビジネスプラン①
「軽度の知的障害や発達特性のある方の就労準備と成長記録を支えるゲーム型アプリ」の構想デモページです。

## 公開URL（sbiu-demo リポジトリに配置した場合）

https://yuya-1204.github.io/sbiu-demo/workstep/

- 閲覧には他のSBI-Uデモと同じ閲覧用パスワードが必要です（デモ用の簡易ゲート。公開時はサーバ側認証に置換）。

## 内容

- 全体フロー: 実作業撮影 → 4段階教材の自動生成 → グループホームで練習 → 達成度8割で現地デビュー
- 4段階トレーニング体験デモ: ①ゲーム（アニメ風2D見本）→ ②ゲーム（体験）→ ③実写（動画視聴）→ ④実写（ゲーム体験）
- 見守りダッシュボード（集中・離席・会話・スマートフォンの各指標／メタテク社の動画認識技術の活用を想定）
- 成長記録・安心への配慮（同意・要配慮情報の取り扱い）

## アップロード方法（GitHub Web UI）

1. https://github.com/yuya-1204/sbiu-demo を開く
2. 「Add file」→「Upload files」
3. `workstep` フォルダごとドラッグ＆ドロップ（`workstep/index.html` になるように）
4. Commit changes
5. 数分後に https://yuya-1204.github.io/sbiu-demo/workstep/ で公開
